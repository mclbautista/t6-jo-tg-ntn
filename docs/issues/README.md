## Keeping them in sync

- The body below each file's `# Title` line is the issue body, character for character. A trailing `Generated by Claude Code` footer that GitHub adds to agent-edited issues is not part of the mirror.
- Write link placeholders as `[Notion row](PAGE_URL)`, not `[Notion row](<page url>)`: GitHub rewrites the angle-bracket form, which breaks the mirror.
- Change the issue and the file together, in the same PR that motivates the change.
- When a ticket closes, keep its file; it becomes the record of what was built.
- The closed design tickets (#1–#17) are mirrored in `map/`.
